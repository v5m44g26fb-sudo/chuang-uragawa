# 担当をデビューさせる件

『担当をデビューさせる件』（PRODUCE 101 JAPAN Season1編）の続編。
実在の番組『創造営2021』（CHUANG 2021／テンセントビデオ、2021年2〜4月、中国・三亜で収録）と実在の人物を題材にした、ファンメイドのIF物語です。史実をもとにしていますが、言動や順位の変動には創作を含みます。

## あらすじ

2019年、『PRODUCE 101 JAPAN』の合宿で交わした「デビューさせる」という約束。
2年後――井汲大翔はRBW JBOYZとして中国の『創造営2021』に挑み、なお（19歳目前）は日本人学員サポートスタッフとして三亜の現場で再会する。

プレイヤーの仕事は、裏側サポートの配分。通訳、Weibo発信、日本側ファンへの発信、体調ケア、作戦会議――その積み重ねが大翔の撑腰値（票）を動かす。
目標は、史実の最終15位を覆し、INTO1（上位11人）としてデビューさせること。

## 遊べる範囲

**第1部**：プロローグ（三亜到着・再会）→ 初評級（「HIP」89票・B班、追加ステージ「CALL CALL CALL！」）→ 第一次公演（「Lover Boy 88」撑腰王・A班昇級）→ 主題曲考核（B班降級）→ 第1回順位発表（史実17位を土台に、サポート配分で変動）。

**第2部（v3で追加・物語完結）**：第二次公演「Therefore I Am」（遊楽園チーム、163票・攻擂あと33票）→ 第2回順位発表（史実12位・自己最高）→ 第三次公演「衛星XL」（慶憐センター＋Amber助陣）→ 第3回順位発表（25人・圏外では離営分岐）→ 決勝・成団夜（「定義」「Fun」、累積でINTO1デビュー／あと一歩に分岐）→ 後日談（INTO1始動／直筆の手紙と写真集『灼熱』）。v2のセーブ（第1部クリア済み）からそのまま第2部に入れます。

## 主な登場メンバー

井汲大翔、田口馨也、隅田隼平、林墨、張嘉元、張騰、謝興陽、張星特、陳俊潔、慶憐、胡燁韜、俞更寅、栄耀、伯遠、利路修、劉宇、贊多、力丸、米卡、高卿塵、尹浩宇、周柯宇、劉彰、メンター陣（鄧超・寧静・劉逸雲・周深・周震南・鄭乃馨）。メンバー画面から写真つきプロフィールが見られます。

さらにv3では**学員90人全員のデータ**（名前・読み・当時の年齢・出身・所属・分班推移・順位推移・結果）を収録し、メンバー画面で検索・閲覧できます。各順位発表の順位表も90人分の史実データ（票数つき）で表示され、動くのは大翔の票だけです。出典はWikipedia（日本語版・中国語版）『創造営2021』『创造营2021节目列表』。
